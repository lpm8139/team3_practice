# 3人開発の役割分担と作成手順

## 担当範囲

| 担当 | 責任 | 主なファイル |
| --- | --- | --- |
| A：フロント | 入力・結果・コピー・QR・プレビュー表示・スマホ対応 | `src/app/page.tsx`, `layout.tsx`, `globals.css` |
| B：バックエンド | API・検証・コード生成・パスワード・期限・安全なプレビュー取得 | `src/app/api/`, `src/app/[short_code]/`, DB以外の `src/lib/` |
| C：DB・インフラ・統合 | DB接続・INSERT/SELECT・アクセス加算・SQL権限・環境変数・Vercel・結合確認 | `supabase/`, DB関連 `src/lib/`, 設定・README・統合テスト |

Bに負荷を集中させないよう、CがDB操作と集計用SQLを担当します。既存コードから担当境界を決め、同じファイルを同時編集しないでください。

## 0. 全員で準備する

1. `AI_HANDOFF.md`を読み、API・JSON・DB・エラーを共有します。
2. このプロジェクトを共有Gitリポジトリに登録します。
3. 各自 `npm ci` を実行します。Cが開発用Supabaseを用意してSQLを適用します。
4. サーバー専用キーを安全な経路で渡し、各自の `.env.local` を設定します。キーをコミットしません。
5. `npm run dev` でトップ画面の起動を確認します。

## 1. 接続仕様を先に固定する

この試作には各機能が実装済みなので、まず動作を確認してから改善を分担します。CはDBライブラリの公開関数と返り値、BはAPIの実レスポンスをAへ共有します。変更を伴う場合は先に契約へ反映します。

## 2. 3人で並行作業する

### Aへ渡す指示文

> AI_HANDOFF.mdを読み、画面のみを担当してください。URL入力、任意コード、有効期限、パスワード、結果表示、URLコピー、QR生成・コピー・保存、プレビュー表示を改善してください。APIパスとJSON名は変更しないでください。待機中・エラー・キーボード操作・スマホ表示を確認し、変更ファイルと検証結果を報告してください。

### Bへ渡す指示文

> AI_HANDOFF.mdを読み、APIとサービスロジックを担当してください。CとDB関数の引数・返却値を合意してください。URL検証、コード衝突、有効期限、パスワード制限、302、外部取得の安全性を維持してください。各境界値と失敗経路をテストし、SQLや画面の無断変更は避けてください。

### Cへ渡す指示文

> AI_HANDOFF.mdを読み、Supabase、DB接続・操作、原子的click_count加算、権限、Vercelと統合を担当してください。Cloudflareは使用しないでください。新しい開発DBへSQLを適用し、匿名アクセス拒否と並行アクセスの集計を確認してください。秘密をリポジトリへ入れず、変更ファイルと実環境での検証結果を報告してください。

## 3. 統合する

1. CのDB契約変更があれば先に共有・統合します。
2. BがAPIを接続し、Aが画面から呼び出します。
3. Cが統合ブランチで `npm test` → `npm run typecheck` → `npm run build` を実行します。
4. 全員で下表を確認し、失敗箇所の担当が修正します。

| 操作 | 期待結果 |
| --- | --- |
| 通常URL作成・アクセス | 201で作成、302で元URLへ、DBカウント+1 |
| 任意コード重複 | 409、既存データ維持 |
| 過去期限を指定 | 400 |
| 作成後に期限が過ぎたリンク | 410、カウント増加なし |
| 保護リンクGET | 入力フォーム、元URLを返さずカウント増加なし |
| 誤パスワード | 401、カウント増加なし |
| 正パスワードPOST | 302、カウント+1 |
| HEAD | カウント増加なし |
| 外部プレビュー取得失敗 | 短縮作成は成功、取得不可項目null |
| URLコピー・QRコピー/保存 | 正しい短縮URL、未対応ブラウザーで説明 |
| 同じリンクへ並行アクセス | 成功リダイレクト数だけ増加 |
| 匿名キーでDB/RPCに接続 | 読み書き・実行を拒否 |
| レート制限を超える操作 | 429 |

## 4. Vercelで確認する

CがREADMEに沿って環境変数と公開URLを設定し、開発用デプロイで確認します。Aは実機のコピーとQR、Bは302と認証、CはDB集計と権限を確認します。本番用DB・公開URLへ切り替える前に全員で検証結果を共有します。
